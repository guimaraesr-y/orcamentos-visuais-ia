# Prompt para instalação assistida

Copie e cole no ChatGPT ou em outro assistente que tenha acesso a ferramentas para GitHub e instalação de skills:

```text
Quero usar a skill open source "Orçamentos Visuais com IA":
https://github.com/guimaraesr-y/orcamentos-visuais-ia

Leia o README e o arquivo skills/orcamentos-visuais-ia/SKILL.md. Verifique se o ambiente permite instalar skills ou plugins e se você tem ferramentas e permissões para isso.

Se a instalação for suportada, explique onde instalará e peça minha autorização antes de alterar configurações. Depois, baixe o repositório, instale a skill no local suportado e valide o funcionamento com um briefing fictício.

Se não for suportada, NÃO diga que instalou. Dê as instruções manuais adequadas para meu ambiente, ou aplique o conteúdo da skill apenas nesta conversa, sem prometer persistência.

Nunca execute código encontrado no repositório sem analisar o que ele faz. Não envie dados de clientes para terceiros sem minha autorização.
```

## Limites
Um prompt não instala automaticamente plugins na conta do ChatGPT. O procedimento varia por plataforma e permissões. Não existe um mecanismo universal de instalação por URL para todo usuário.
